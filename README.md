# Song Lai Personal Website

This repository hosts a simple static personal academic homepage for `https://laisong-22004009.github.io/`.

## Structure

- `index.html`: the single-page homepage.
- `assets/css/site.css`: minimal styling.
- `images/profile.jpg`: profile image used by the homepage.

## Local Preview

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8765/`.
